# educational User Story

## Login / Registration

**Title:** Application registration  
As a user, I want to register by entering my username, email, and password and clicking the Sign Up button, so that I can create an account.  
**Example:** A new student types a username, email, and password, then taps Sign Up to start learning.  
**Why:** Gives each learner a personal account to save courses and progress.  

**Title:** Application login  
As a user, I want to log in with my email and password using the Login button, so that I can access my account.  
**Example:** A returning student enters their email and password and taps Login to reach their courses.  
**Why:** Keeps learning data private and gives quick access to saved content.  

**Title:** Error feedback on signup and login  
As a user, I want to receive a message if I click Sign Up without entering my details, or if I enter an incorrect username or password, so that I know what went wrong.  
**Example:** Tapping Sign Up with empty fields shows "Please fill in all fields", and a wrong password shows "Login unsuccessful".  
**Why:** Helps users fix mistakes quickly instead of feeling stuck.  

**Title:** Store user data  
As a user, I want my details saved in local storage, so that my data persists between app sessions.  
**Example:** After registering, the student closes and reopens the app, and their details are still available.  
**Why:** Avoids re-entering information every time the app is opened.  

## Home Screen

**Title:** Overview of my data  
As a student, I want to view an overview of my learning data on the home screen, so that I can monitor my progress at a glance.  
**Example:** The home screen shows enrolled courses, completed lessons, and the current study streak.  
**Why:** Helps students stay motivated by seeing their progress immediately.  

**Title:** Introductory guide for new users  
As a new student, I want to see a quick introductory guide on the home screen, so that I can learn how to use the app.  
**Example:** A carousel of tips explains how to find courses, watch lectures, and submit homework.  
**Why:** Ensures new users quickly understand the key features.  

**Title:** Quick access to most-used features  
As a student, I want to access my most-used features from the home screen, so that I can navigate the app efficiently.  
**Example:** Shortcuts on the home screen lead to My Courses, Assignments, and Saved Lectures.  
**Why:** Reduces clicks for common actions and improves the user experience.  

## Detail Screen

**Title:** Detailed information on a course  
As a student, I want detailed information on a selected course, so that I can make informed decisions.  
**Example:** The detail screen shows the course title, instructor, syllabus, duration, and ratings.  
**Why:** Helps students decide if a course fits their needs before enrolling.  

**Title:** Save or share from detail screen  
As a student, I want to save or share a course from the detail screen, so that I can keep or share useful content.  
**Example:** Students tap Save to add a course to their list, or the share icon to send it to a classmate.  
**Why:** Encourages interaction and sharing.  

**Title:** View related courses  
As a student, I want to view related courses on the detail screen, so that I can explore more options.  
**Example:** A "Python Basics" page lists other beginner programming courses.  
**Why:** Offers helpful suggestions and keeps students engaged.  

## Persistent Data

**Title:** Persist login state  
As a user, I want my data, like login state, to persist across sessions, so that I don't need to re-enter details every time.  
**Example:** The app keeps the student logged in until they tap Logout.  
**Why:** Saves time and provides seamless access.  

**Title:** Save preferences  
As a user, I want to save my preferences, such as dark mode, so that the app remembers my settings.  
**Example:** A student who chose dark mode sees dark mode again when reopening the app.  
**Why:** Improves comfort and user satisfaction.  

**Title:** Persist user activity logs  
As an admin, I want user activity logs to persist, so that I can track and analyze trends over time.  
**Example:** The app stores quiz performance and lesson completion to generate progress reports.  
**Why:** Enables long-term analysis and helps improve student retention.  

## External API

**Title:** Real-time weather updates  
As a student, I want to view real-time weather updates on the home screen, so that I can plan my day effectively.  
**Example:** The app shows if it is sunny or rainy, helping the student decide whether to go to a study center or study at home.  
**Why:** Provides relevant external data that improves the app's value.  

**Title:** Live currency conversion rates  
As a student, I want to see live currency conversion rates when buying a course, so that I can make informed financial decisions.  
**Example:** Paid courses show prices in the student's preferred currency.  
**Why:** Creates a personalized and convenient experience.  

**Title:** Nearby places on a map  
As a student, I want to see nearby study centers or libraries on a map, so that I can choose a place to study conveniently.  
**Example:** A map API shows libraries and learning centers close to the student's location.  
**Why:** Improves navigation and helps users make better choices.  

## Settings Menu

**Title:** Access settings from any screen  
As a user, I want to access a settings menu from any screen, so that I can adjust preferences at my convenience.  
**Example:** A settings icon in the top-right corner of every screen opens the settings menu.  
**Why:** Easy access encourages users to customize their experience.  

**Title:** Categorized settings sections  
As a user, I want to see categorized sections in the settings menu, so that I can quickly find the options I need.  
**Example:** Settings are grouped into Profile, Appearance, Notifications, and Account.  
**Why:** Logical organization reduces user effort.  

**Title:** Admin control of settings  
As an admin, I want to enable or disable certain settings for users, so that I can maintain app security and compliance.  
**Example:** An admin dashboard has toggles to restrict access to sensitive settings.  
**Why:** Ensures user settings follow institution policies.  

## Settings Screen

**Title:** Enable dark mode  
As a user, I want to enable dark mode in the settings screen, so that I can reduce eye strain during nighttime studying.  
**Example:** A toggle under the Appearance section switches between light and dark mode.  
**Why:** Improves accessibility and comfort.  

**Title:** Notification preferences  
As a user, I want to adjust notification preferences, so that I only receive alerts relevant to me.  
**Example:** Students turn on alerts for assignment deadlines but turn off promotional alerts.  
**Why:** Personalized notifications prevent annoyance and keep users engaged.  

**Title:** Update email and password  
As a user, I want to update my email and password on the settings screen, so that I can keep my account secure.  
**Example:** An Account section lets users change their credentials.  
**Why:** Ensures security and user satisfaction.  

## Notifications

**Title:** Daily reminder notification  
As a student, I want to receive a daily reminder notification, so that I don't forget to study.  
**Example:** The app sends a notification at 6 PM reminding the student to continue their course.  
**Why:** Encourages consistent app usage.  

**Title:** New feature and course notifications  
As a student, I want to receive notifications about new features and courses, so that I can explore and benefit from them.  
**Example:** The app notifies students when a new course in their favorite subject is added.  
**Why:** Drives engagement and satisfaction.  

**Title:** Turn off promotional notifications  
As a user, I want to turn off promotional notifications, so that I can focus on essential updates only.  
**Example:** A setting disables promotional alerts but keeps assignment deadline reminders active.  
**Why:** Reduces frustration and builds trust.  

**Title:** Targeted notifications by admin  
As an admin, I want to send notifications to specific user groups, so that I can target them with relevant information.  
**Example:** An admin notifies students who completed the beginner course about a new advanced course.  
**Why:** Improves targeted communication and engagement.
